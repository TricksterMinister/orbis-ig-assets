# orbis-ig-assets

Public image host for ORBIS social posts (Instagram carousels, reels covers, highlight covers).

**Why public:** the Instagram Graph API fetches media by public URL and cannot read Google Drive. The content factory publishes images here and passes their `raw.githubusercontent.com` URLs to Instagram.

**Contents:** images only. No code, no credentials, no personal data. Do not add anything else to this repository.

Folders: `carousel/`, `reels/`, `probe/`, `test/`, plus highlight covers (`hlcover_*.jpg`) and triptychs in the root.
