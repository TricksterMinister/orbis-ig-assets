# orbis-ig-assets

Public media hosting for ORBIS social posts. Social platforms consume raw file
URLs from this repo, so every push publishes instantly and publicly.

Rules for any agent or human committing here:

- Media files only (images, video). No code, no documents.
- Never commit: credentials or keys, internal documents, client data, pricing.
- Internal instructions and the estate map live in the private ORBIS
  repositories, not here.
